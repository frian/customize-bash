## 2.0.0 (2026-10-30)
* Added non-destructive install and uninstall scripts with dry-run and backups.
* Source configuration directly from the checked-out repository, with idempotent ~/.bashrc hooks.
* Keep named profiles and profile modules, and support user-local overrides and modules.
* Migrate the legacy startup hook without deleting old files; deprecate the old installer.
* Add a Bash-only installation test suite.
